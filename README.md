# 🎁 Bumper Festive Bonanza 2026

A mobile-first festive campaign landing page featuring an interactive rewards calculator, dynamic podium carousel, live real-time ticker, and festive rewards catalog bottom sheet.

## ✨ Key Features
- **Hero Podium Carousel**: High-impact auto carousel displaying top bumper prizes (Royal Enfield Bullet 350cc, iPhone 17, and Laptop) over a festive arch stage.
- **Interactive Lead Goal Calculator**: Smooth slider with zero-latency Pointer Capture, device vibration haptics (`navigator.vibrate`), and audio feedback syncing reward graphics dynamically with lead targets.
- **Center-Focus Rewards Scroller**: Seamless infinite scrolling carousel that zooms only when an item is in the viewport center.
- **Complete Festive Rewards Catalog**: Bottom sheet with detailed milestones from 20 to 1000 leads.
- **Live Activity Ticker**: Real-time floating ticker showcasing recent leads added by advisors.
- **Countdown Timer**: Highlighting the festive campaign closing date.
